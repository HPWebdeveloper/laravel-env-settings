This repository is structured to be used as a GitHub template for Laravel packages. For a hands-on quickstart, see `doc/fresh-setup.md`.

## What this template includes

- Composer scaffolding with Laravel package conventions
- CI workflows (tests across PHP/Laravel versions, PHPStan, Pint, release)
- Pre-commit Pint hook via `.githooks/pre-commit`
- A `bin/bootstrap` script to rename namespaces, provider, and config key/file interactively

## How to use as a template

1. Make this repo a Template on GitHub (Settings → General → Template repository)
2. Click "Use this template" → Create a new repository
3. Follow `doc/fresh-setup.md` for the bootstrap flow
